# 통합 체크리스트
상태는 미검증 / 통과 / 실패 / 해당 없음으로 기록한다. 체크박스만으로 검증 증거를 대체하지 않는다.

| 시나리오 | 기대 결과 | 상태 | 근거 / 담당 |
| --- | --- | --- | --- |
| 로그인·GitHub 연동 | 서비스 인증과 GitHub 접근 실패를 구분 | 미검증 | FE·BE |
| 사전 분석 요청 | 접수 결과와 runId 전달 | 미검증 | FE·BE·AI |
| 분석 진행·실패 | HTTP 오류와 분석 작업 실패를 구분 | 미검증 | FE·BE·AI |
| 부분 분석 실패 | 유효 결과 유지·실패 범위 표시 — 계약 결정 필요 | 미검증 | FE·BE·AI |
| 면접 시작 | interviewId/sessionId 연결 및 중복 요청 정책 확인 | 미검증 | FE·BE·AI |
| 텍스트 답변·꼬리질문 | 합의된 WS 형식, 단일 면접관·페르소나 적용 | 미검증 | FE·BE·AI |
| 근거 조회 실패 | 없는 근거를 만들지 않고 합의된 실패 처리 | 미검증 | BE·AI |
| 면접 종료·리포트 | 진행 상태와 생성 중/완료/실패 표시 일치 | 미검증 | FE·BE·AI |
| 재접속·중복 이벤트 | 합의된 재연결·중복 방지 정책 검증 | 미검증 | FE·BE |

현재 런타임은 스켈레톤을 포함한다. 위 시나리오는 구현 완료 선언이 아닌 향후 통합 검증 목록이다.
