# 0034 로컬 LLM의 xhigh와 모델 출력 한도 설정

- 상태: Proposed — 사용자 요청으로 개인 로컬 환경에 적용하는 설정. 공유 운영 기본값의 합의와 구분한다.
- 날짜: 2026-11-07
- 관련: [0032 공급자 호환과 예산](0032-provider-compatibility-and-source-budgets.md), [#196](https://github.com/kakaotechcampus-4/ktc4-chonnam-3/issues/196)
- 사양 근거: [공식 gpt-6-luna 모델 사양](https://developers.openai.com/api/docs/models/gpt-6-luna)
- 실행 결과: [단일 구현 기록](../implementation.md#llm-xhigh-limit-20261107)

## 맥락

사용자가 기존 로컬 환경의 LLM 추론 강도를 `xhigh`, 출력 예산을 최대 상한으로 지정하도록 요청했다.
모델의 문서상 출력 한도와 프록시의 요청 파라미터 허용 범위, 실제 생성·완료한 분량은 서로 다르다.
출력 예산만 늘리고 기존 비스트리밍·응답 바이트·시간 제한을 유지하면 실행 조건이 일치하지 않는다.

## 결정과 이유

- 모델은 기존 `gpt-6-luna`를 유지한다. 추론 강도는 사용자 지정 `xhigh`를 사용한다.
- 출력 예산은 공식 모델 한도인 128,000토큰으로 지정한다. 요청 정수값 수락만으로 모델 한도를 새로 정의하지 않는다.
- 현재 공급자의 비스트리밍 제약에 맞춰 스트리밍을 사용한다. 최종 JSON의 완료·계약 검증 경계는 유지한다.
- 입력은 이전 실제 레포·Director 검증의 262144바이트, 응답은 전체 SSE에 대한 유한 상한 67108864바이트로 제한한다.
  응답 상한은 모든 가능한 이벤트 분할·문자 인코딩을 수용한다는 수학적 보증이 아니다.
- 호출당 시간 제한은 50초로 둔다. 기존 준비 source 제한과 600초 worker 제한을 유지하고 무제한 실행으로 바꾸지 않는다.
  최대 출력 설정이 모든 요청에서 128,000토큰을 생성하거나 그 분량의 완성을 보장한다는 뜻은 아니다.
- 원본 환경의 대상 LLM 필드만 바꾼다. 자격증명·다른 공급자 설정·주석·공유 기본 예시는 보존한다.

## 영향과 후속 범위

설정을 읽는 AI 작업에 전역 적용되므로 새 강도에서의 기능·품질 검증을 별도로 기록한다.
실행 중인 API·worker는 설정을 다시 읽어야 하며, 기존 측정치를 새 설정의 검증 결과로 옮기지 않는다.
호출 예산·입력·시간·완료 검사와 Director 후보 검수는 유지하며, 공급자 연결 성공을 서비스 전체 완주로 계산하지 않는다.
