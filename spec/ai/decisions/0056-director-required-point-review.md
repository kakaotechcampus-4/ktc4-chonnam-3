# 0056 Director 질문의 필수 확인점별 독립 검토

상태는 2026-11-11 로컬 실험 개발·평가 채택이다.

## 맥락

기존 검토의 전체 계약 판정 하나로는 실제 질문에 없던 설명을 필수점에 넣는 오류를 놓칠 수
있다. 질문이 이미 저장되면 T3가 그 항목을 미답으로 판단하고 같은 목적의 후속 질문을
허용할 수 있다.

## 결정

- v14는 기존 한 번의 Review 요청에서 후보의 필수점 키별 판정과 질문 원문 구절을 받는다.
  전체 계약의 양방향 일치, 평가 범위, 문장·전제·문답의 검토도 유지한다.
- 코드는 키 집합과 인용 원문을 검증한다. 필수점 하나라도 질문에서 직접 요구되지 않거나
  판정이 불명확하면 전체 계약을 적합하다고 표시했어도 확정하지 않는다. 질문과 계약을
  수정하지 않은 상태에서 독립 검토하며, 형식 오류와 의미 반려는 기존 실패 경로로 구분한다.
- 유효한 반려는 현재 재작성·재계획·안전한 대안 없음 분류를 따른다. 복구는 원래 버전과
  응답 스키마가 일치하는 실제 두 시도에서만 복원한다. 저장된 이전 질문·분석을 재작성하거나
  Controller의 자동 슬롯을 늘리지 않는다.
- 평가 장부는 실제 정책·질문·응답 지문과 필수점 판정을 결합한다. 인용이 질문에 있다는
  검사는 그 요구가 의미상 포함됐다는 증명이 아니다. 정확히 같은 후보를 재검토하는 비교와
  전체 생성·검토 비교로 잘못된 승인과 거절, 실제 지연을 확인한다.

## 영향

v1~v13 Review 응답 형식과 공개 REST·WS, 저장 Question Contract, T3 채점 형식은 유지한다.
새 진단은 평가에 사용하며 사용자 응답과 관측 서비스에 원문을 전송하지 않는다. 현재 결과와
기본 버전 선택은 [구현 기록](../implementation.md)에 남긴다.
