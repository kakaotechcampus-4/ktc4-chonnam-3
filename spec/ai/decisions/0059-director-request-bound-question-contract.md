# 0059 실제 요청 전체에서 구성하는 질문 계약

상태: 2026-11-11 로컬 실험 개발·평가 채택.

## 맥락

실제 질문에서 선택만 요구했는데 계약은 별도 이유·영향·직무 관계 설명까지 요구하는
경우가 있었다. 모델이 질문 원문을 인용해도 그 인용이 모든 계약 의무를 뒷받침하지는
않는다. 독립 검토 정책의 축약과 응답 스키마 고정만으로 해결되지 않아, 생성 단계의
계약 구성에서 자유로운 요구 확장을 줄인다.

## 결정

- v17의 사적 Plan은 `director-plan.v4`다. 질문을 사실·명시적 가정의 `preamble`과 답을
  요구하는 `request`로 나눈다. 요청·지시·의문은 request에만 둔다.
- 모델은 자유로운 purpose·required_point.description·evaluation_scope를 생성하지 않는다.
  `point_key` 하나와 기존 참조·가정·평가 키를 제안한다. 코드는 배경과 요청을 공개 질문
  본문으로 조합하고, purpose와 단일 필수점 설명을 request 전체로 구성한다. 평가 범위는
  직접 질문한 답만으로 제한하는 고정 문구다. 가정도 표시된 문장의 연속 원문과 결합한다.
- request의 일부만 고르면 이유·AND/OR 같은 실제 요구를 빠뜨릴 수 있으므로 첫 후보는
  request 전체를 하나의 필수점으로 사용한다. 기존 AnswerAnalysis의 동일 키를 covered와
  missing 양쪽에 두는 partial을 활용하고, 실제 부족한 부분은 인용·limitations로 구분한다.
- 부분 답변에서 이미 정한 선택·범위는 다음 질문의 고정 조건으로 보존한다. 질문이
  반대쪽의 처리나 비교를 직접 요구하지 않았다면, 같은 결정을 부정형으로 재진술하지
  않았다는 이유로 미답을 추가하지 않는다. 후속은 실제 미답만 다루며 새로운 조건으로
  재판단할 때는 그 조건을 명시한다. 가정형 선택을 코드의 구현 주장으로 승격하지 않는다.
- 독립 Review v3는 유지한다. 잘못된 전제·직무와 무관한 목적·반복·유도·과도한 복합 요청,
  배경에 섞인 의문 및 최종 질문과 계약의 불일치를 계속 검토한다. 문자열 결합 검사는
  자연어 의미를 완전히 증명하는 장치가 아니다.
- 새 생성·원시 시도 저장·복구·사적 평가 원문은 동일한 버전별 Plan 디코더를 사용한다.
  v17은 Planv4로만 복원한다. 과거 버전의 생성·저장 형식과 실제 면접 원문은 보존한다.
  공개 Question·REST·WS·DB 형식, 호출·복구 상한, Controller의 권한·종료 책임은 유지한다.
- v17의 생성 요청 스키마는 Controller의 실제 main·follow_up 선택지별로 Persona·부모·
  평가 키·필수점 키를 함께 제한한다. 후속 선택지가 없으면 main/null만 제안할 수 있다.
  새 생성의 assumptions는 빈 배열로 제한하고, 필요한 조건은 표시 문장에 쓴다. 기존
  v17 기록의 유효한 원문 인용 가정은 계속 복원한다. 참조·키 중복·정확한 후속 결합은
  기존 실행 검사로도 확인하며, 스키마만으로 모든 잘못된 출력을 막았다고 간주하지 않는다.

## 이유와 제한

질문과 계약을 각각 자유롭게 생성한 뒤 의미 일치를 검사하는 과정에서 생기는 확장을
줄일 수 있다. 잘못된 계약의 필수점을 저장 후 삭제하거나 판정을 충분으로 덮어쓰는
방식은 사용하지 않는다. 새 형식의 디코딩 규칙에 따라 전달 전 계약을 처음 구성한다.

단일 필수점은 부족한 세부 내용을 key만으로 구분하는 해상도가 낮다. 한 판단에 필요한
여러 관찰 중 일부만 답한 경우, 후속 질문이 답한 부분을 반복하지 않는지 실제 분석과
후속 정책으로 확인한다. preamble에 요청이 섞이는 반례도 별도로 검증한다.

기존 불일치 계약을 거절하는 평가와 같은 문장에 새 계약을 구성한 평가는 다른 사례다.
계약을 바꾼 뒤 원래 reject 정답을 재사용해 검토 정확도가 좋아졌다고 설명하지 않는다.
안전한 대안을 잘못 없다고 판단하는 다른 원인까지 해결됐다고 확대하지 않는다.
실제 실행 결과와 기본값 선택은 [구현 기록](../implementation.md)에 남긴다.
