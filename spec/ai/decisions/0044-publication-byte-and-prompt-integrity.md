# 0044. 게시 시 평가 원본 바이트와 프롬프트 문자 보존

- 날짜: 2026-11-09
- 상태: Accepted
- 관련 결정: [Director 턴과 참조 범위](0043-director-turn-state-and-reference-constraints.md)

## 맥락

로컬에서 보존한 평가 원본의 raw SHA256은 Git 줄바꿈 변환으로 달라질 수 있다.
또한 복구 프롬프트의 추가 문단이 작성 경로의 문자 인코딩 때문에 손상된 사실을 확인했다.
실행 이력과 과거 평가 출처를 덮어쓰면 어느 입력을 검증했는지 추적할 수 없다.

## 결정

- 과거 평가 snapshot의 원본 바이트와 해시를 유지하고 해당 디렉터리에 `-text`를 적용한다.
- 실제 Git commit과 LF·CRLF 환경의 checkout 후 원본 해시와 cohort binding을 검사한다.
- 손상된 미게시 v7은 로컬 원본과 보존 지문으로 남기고 정상 UTF-8 본문의 v8을 게시한다.
- v8은 v6의 기존 정책 본문을 보존하고 유한 복구 피드백 지침만 추가한다.
- runtime과 복구 Controller는 기존에 저장된 v7과 새 v8을 함께 지원한다.
- 기존 실행 세션·DB의 프롬프트 원문과 버전은 소급 변경하지 않는다.

## 이유와 영향

동일한 원문을 다른 운영체제에서 검증할 수 있고, 이전 실행과 수정 후 검증을 구분할 수 있다.
현재 canonical 평가 입력을 과거 snapshot으로 대체하거나 과거 검수 상태를 승격하지 않는다.
자동 복구 횟수와 독립 Review 기준은 변경하지 않는다.
새 버전의 정적·모의 검증과 실제 모델 실행 검증은 별도로 기록한다.
구현·실행 결과의 원본은 [구현 기록](../implementation.md)이다.
