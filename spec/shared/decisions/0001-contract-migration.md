# 0001 공통 계약의 단계적 이관
- 상태: Proposed
- 작성일: 2026-09-09
- 관련 PR: 없음 — 검수 전
- 검토자: FE·BE·AI 리드 미확정

## 맥락
API 정보가 FE 명세·타입과 BE 변경표에 나뉘어 있다. 이름·단계·프로토콜의 차이를 해소해야 한다.

## 제안
spec/shared/contracts를 목표 원본으로 삼되, 일치하는 항목부터 스키마로 옮긴다. 이번 초안은 GET /me와 에러 구조에 한정한다.
모든 API를 한 번에 대체하는 방안은 현재 충돌과 미구현 범위를 가리므로 채택하지 않는다.

## 영향·되돌리기
FE·BE·AI 모두 검수. 기존 상세 문서는 유지한다. 각 항목의 구현·타입·테스트가 맞은 뒤 원본 링크를 변경한다.
검수에서 거절하면 초안 계약 파일과 이 결정의 상태를 갱신하고 기존 기준을 유지한다. 런타임 변경은 없다.
