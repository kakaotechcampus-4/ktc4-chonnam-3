# 0046 — 공식 자료의 식별·언어와 유한 수집 경계

- 상태: Accepted for local implementation
- 날짜: 2026-11-09
- 관련: PR #225 리뷰 후속, 0039의 공식 자료 식별·수집 세부 보완
- 승인 범위: 사용자 요청에 따른 구현·리뷰 반영. 팀 공통 운영 승인과 구분한다.

## 맥락

카탈로그의 검증 날짜나 설명만 바뀌어도 기존 원문을 다시 받는 문제가 있다.
질문 작성 언어를 자료 언어 요구로 간주하면 한국어 질문과 영어 문서를 연결하지 못한다.
페이지 전체를 모델 전달량과 같은 크기로 자르면 뒤쪽의 필요한 절을 잃는다.
여러 자료 중 하나의 저장 실패로 다른 자료와 외부 사용량 기록까지 사라져서는 안 된다.

## 결정

- 내용 적합성 식별에는 URL·요청 절·기술·버전·언어·분류·검색어·접근 상태를 포함한다.
  검증 시각과 설명용 limitations는 식별에서 분리한다. 원본 provenance는 보존한다.
  과거 전체 메타데이터 해시는 당시 provenance의 해시와 현행 적합성 식별을 모두 검증한
  경우에만 재사용한다. 접근 정책이 달라진 원문을 무조건 재사용하지 않는다.
- 자료 언어는 질의가 명시할 때만 제한한다. 질문 작성 언어와 원문 언어를 구분한다.
  한영 기술·개념 별칭은 닫힌 목록으로 대응시키고 버전·API 식별자·원문 관련성 검사는 유지한다.
  결정적 문자열 대응을 의미 품질 승인으로 해석하지 않는다.
- 수집용 원문은 최대 196608자, 보존·전달할 요청 절은 최대 24000자로 각각 제한한다.
  수집 응답은 별도 4MiB 상한을 적용한다. 좌표는 실제 추출 원문 줄을 기준으로 보존한다.
  필요한 제목·완전한 절이 없거나 예산을 넘으면 채택하지 않고 그 한계를 기록한다.
- catalog의 공개 URL 확인과 공급자의 실제 추출 성공을 구분한다. 실제 결과는 실행별로
  성공 snapshot·실패 사유·호출·크레딧을 기록한다. 일부 성공을 전체 지원으로 확대하지 않는다.
- 저장은 항목별 트랜잭션으로 처리하고 실패해도 이미 사용한 외부 크레딧은 감사에 남긴다.
  감사 파일은 덮어쓰지 않는다. 충돌하면 고유 run ID를 가진 새 경로를 사용한다.
- 일반 서비스 SQL의 UPDATE·DELETE·TRUNCATE로 공유 원문을 변경하지 못하게 한다.
  DB 소유자가 트리거·권한·스키마를 변경하는 관리 행위까지 막는 보장은 하지 않는다.
  데이터가 있는 downgrade는 거절하며 검증 편의를 위해 원문을 지우지 않는다.

## 대체 관계와 영향

0039의 단일 수집/전달 크기와 카탈로그 전체 메타데이터 식별 세부를 위 규칙으로 보완한다.
공식 도메인 허용 목록, 사용자별 인용 소유권, 비신뢰 원문 처리와 단일 Director 원칙은 유지한다.
공개 API 변경은 없다. 초기화는 운영 startup에 추가하지 않고 명시적인 개발·시험 수집만 허용한다.
구현 위치·실행 결과·실제 추출의 미확인 범위는 [구현 기록](../implementation.md)에 둔다.
