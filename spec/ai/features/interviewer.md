## 평가 조건
- 고정 평가 데이터셋으로 질문의 근거 일치·적절성·꼬리질문 연관성 확인.
- 없는 근거의 생성, 도구 실패, 잘못된 구조화 출력, 반복 질문을 포함.
- 모델/provider, prompt 버전, 데이터셋 버전, 비용·지연시간·품질 결과 기록.
- 단위 테스트에서 외부 LLM 호출을 대체하고 실제 LLM 평가와 구분.
- 합격 임계값·모델·저장소는 아직 확정으로 기록하지 않음.
