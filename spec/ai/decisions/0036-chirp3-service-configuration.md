# 0036 — Chirp 3 HD의 서비스 음성 설정

상태: Accepted. 2026-11-08 사용자가 청취한 음성을 채택하고 서비스 설정을 요청한 범위다.
운영 배포나 확인되지 않은 무료 잔여량의 승인을 뜻하지 않는다.

## 맥락

질문은 단일 Director가 확정하며 TTS는 저장된 질문을 음성으로 전달한다.
세 페르소나는 서로 다른 음성을 사용하되 질문의 내용이나 판정을 바꾸지 않는다.

## 결정

1. 공급자는 Google Cloud Chirp 3 HD, 언어는 `ko-KR`로 둔다.
2. 기본 배정은 기술 `Charon`, 도메인 `Kore`, HR `Aoede`다.
   전체 음성 ID는 `ko-KR-Chirp3-HD-` 접두사를 사용하며 환경 설정에서 관리한다.
3. 월 100만 문자는 앱의 최대 상한이다. 실제 무료 잔여량과 같다고 가정하지 않는다.
   프로젝트의 다른 사용과 진행 중 합성을 확인한 뒤, API와 동일한 Redis에 확인한 잔여량으로
   월 예산을 명시적으로 초기화한다. Redis 교체·월 전환 시 자동 한도 복구를 하지 않는다.
4. 키는 비공개 환경 설정에만 두며 브라우저와 공개 예제·검증 로그에 노출하지 않는다.
   worktree에서도 실제 사용하는 설정 파일을 명시하고 실행 중인 API에는 재시작으로 반영한다.
5. 기존 인증·소유권 검사, 원문 재확인, 캐시·동시 요청 병합과 예산 예약을 유지한다.
   합성이나 자동재생 실패는 질문 텍스트로 대체하며 면접 내용을 다시 생성하지 않는다.
6. Gemini-TTS는 이번 선택에 포함하지 않는다. 공급자를 추가할 때는 별도의 인증·사용량 예산·
   응답 형식과 모델·음성·스타일별 캐시를 검토한다.
