# 통합 체크리스트
상태는 미검증 / 통과 / 실패 / 해당 없음으로 기록한다. 체크박스만으로 검증 증거를 대체하지 않는다.

| 시나리오 | 기대 결과 | 상태 | 근거 / 담당 |
| --- | --- | --- | --- |
| 로그인·GitHub 연동 | 서비스 인증과 GitHub 접근 실패를 구분 | 미검증 | FE·BE |
| 사전 분석 요청 | 접수 결과와 runId 전달 | 미검증 | FE·BE·AI |
| 분석 진행·실패 | HTTP 오류와 분석 작업 실패를 구분 | 미검증 | FE·BE·AI |
| 부분 분석 실패 | DB partial → FE failed, 유효 결과 조회·실패 범위 표시 — 확정 계약의 실제 연결 검증 | 미검증 | FE·BE·AI |
| 면접 시작 | interviewId/sessionId 연결 및 중복 요청 정책 확인 | 미검증 | FE·BE·AI |
| 텍스트 답변·꼬리질문 | 합의된 WS 형식, 단일 면접관·페르소나 적용 | 미검증 | FE·BE·AI |
| 근거 조회 실패 | 없는 근거를 만들지 않고 합의된 실패 처리 | 미검증 | BE·AI |
| 면접 종료·리포트 | 진행 상태와 생성 중/완료/실패 표시 일치 | 미검증 | FE·BE·AI |
| 재접속·중복 이벤트 | 합의된 재연결·중복 방지 정책 검증 | 미검증 | FE·BE |

현재 런타임은 스켈레톤을 포함한다. 위 시나리오는 구현 완료 선언이 아닌 향후 통합 검증 목록이다.

## 보류한 화면 보완

2026-09-22 사용자 요청에 따라 아래 4묶음은 기록만 유지하고 수정을 보류한다. 문서·주석 정리로 보류를 해제하거나 구현 완료로 표시하지 않는다.

| 항목 | 남은 보완과 기록 위치 |
| --- | --- |
| 업로드 화면 | 포트폴리오 지원 형식·불필요한 자소서 업로드 처리. 용량 20MB는 이미 확정. [분석 작업](../../frontend/docs/task-09-analysis.md) |
| 저장소 선택 | 개별 `partial` 저장소의 선택 제한을 기존 L1 성공 조건에 맞추는 작업. [분석 작업](../../frontend/docs/task-09-analysis.md) |
| 리포트 통신 오류 | 일반 오류에서 오류 안내 코드가 다시 예외를 내는 문제. [리포트 작업](../../frontend/docs/task-11-report.md) |
| 부분 실패 후 이동 | 전체 분석에서 성공한 다른 저장소의 결과로 이어지는 화면 경로. 버튼 방식은 제안으로만 보존. [분석 작업](../../frontend/docs/task-09-analysis.md) |

이는 기존 검토 범주 안의 미완료 작업이며 새로운 정책 질문 목록이 아니다. 인증을 포함한 실제 기능 구현·연결과 전체 통합 검증은 별도 작업으로 남는다.
