# handoff

git status와 현재 작업 문서를 근거로 .claude/scratch/handoff-YYYYMMDD-HHMMSS-<topic>.md를 새로 작성한다. 같은 파일이 있으면 덮어쓰지 않고 이름을 구분한다.
내용: 목표, 브랜치·기준 ref, 수정 파일, 완료 작업, 실행한 검증과 결과, 미완료·결정 대기, 다음 1~3개 행동, 관련 문서·PR 링크.
비밀키·토큰·원문 이력서·개인정보는 넣지 않는다. 기억에 없는 성공을 추정하지 않는다.
이 경로는 gitignore되므로 팀 공유 문서가 아니다. 팀이 알아야 할 결정은 기존 승인 범위 안에서 spec 또는 PR 본문 초안으로 옮긴다.
메모 작성이 commit/push/메시지 전송 권한을 뜻하지 않는다.
