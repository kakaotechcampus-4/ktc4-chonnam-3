# 0057 Director 공통 정책 배치 비교와 지연 측정

상태는 2026-11-11 로컬 실험 개발·평가 채택이다.

## 맥락

지침을 줄인 후보에서도 추론 출력과 대기 시간이 늘었다. 두 단계가 서로 다른 정책을
읽는 후보는 기존 버전과 실제 입력 캐시량도 달랐다. 정책 길이와 캐시·추론·시간을 함께
확인할 비교가 필요하다.

## 결정

- v15는 v14의 문답 입력, 필수점별 검토, 복구 조건을 사용하고 하나의 전체 정책을
  Plan과 Review에 동일하게 전달한다. 실제 operation과 출력 스키마가 각 단계의 일을 정한다.
- 동일한 등록 정책·typed 입력을 사용한 v14와 비교한다. 과거 버전의 정책 배치는 유지한다.
  실제 생성한 질문과 검토 결과, 캐시·추론 토큰, 시도 수와 서비스 시간을 보존한다.
- 공통 정책은 모델이 읽는 지침의 양도 바꾸므로 이 비교만으로 캐시의 인과 효과를 분리하지
  않는다. 이전 요청의 캐시 상태도 함께 기록하며 품질을 저하시킨 빠른 결과를 채택하지 않는다.
- 평가 DB는 앱과 같은 연결 풀·루프백 주소를 사용한다. 원래 하네스의 연결 설정과 측정은
  보존하고 모델 시간과 DB·조회·저장의 시간을 구분한다.

## 근거와 영향

공식 문서는 동일한 프롬프트 앞부분의 재사용과 설정·구조화 출력이 캐시에 미칠 수 있는
영향을 설명한다. 이 서비스의 MLAPI에서 실제 이득이 생기는지는 사용량과 시간을 측정해
판단한다. [OpenAI 프롬프트 캐시 문서](https://developers.openai.com/api/docs/guides/prompt-caching)

모델·추론 강도·토큰 상한과 공개 API·DB 스키마는 기존 값을 사용한다.
