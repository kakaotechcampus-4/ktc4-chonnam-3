# 0055 Director의 생성·검토 지침 분리와 실제 자료 비교

상태는 로컬 실험 개발·평가 채택이며 날짜는 2026-11-11이다.

## 맥락

질문 생성과 독립 검토가 한 정책 본문을 공유한다. 단계에 필요하지 않은 지침을 줄이면
판단에 걸리는 시간이 달라질 수 있다. 앞선 실험에서 입력 본문 축소가 실제 시간 감소로
이어지지 않아 같은 자료와 설정의 실제 요청 비교가 필요하다.

## 결정

- v13은 하나의 등록 정책을 공통·질문 생성·독립 검토로 구분한다. 각 모델 요청은 공통
  규칙과 자기 단계의 지침을 사용한다. 세 절의 순서·중복·빈 내용을 등록과 호출 전에 검증한다.
- 두 요청의 원문·문답·검증 범위는 같게 유지한다. 실제 질문과 계약은 검토에 전달한다.
  이전 반려의 복구 피드백은 생성에서만 사용한다. 등록 정책 버전·모델을 두 요청에 유지하고
  평가 기록에는 단계별 실제 정책 본문과 지문을 남긴다.
- 전체 답변 표시와 복구는 [0054](0054-director-dialogue-view-and-bounded-replan.md)의
  범위를 사용한다. Controller의 참조·호출 상한, 독립 검토, 저장·종료 책임을 유지한다.
  v1~v12는 등록한 본문을 각 요청에 그대로 사용한다.
- 공개 레포의 고정 커밋·원문 위치, 실제 공고의 선택 필드와 합성 문답을 결합한 자료로 비교한다.
  같은 레포·공고의 변형은 같은 그룹에 둔다. 개발 중에 확인한 자료와 최종 확인 그룹을 분리한다.
  형식·저장 검사와 Codex 원문 판정, 서비스 Review, 실제 요청의 시간과 토큰을 각각 기록한다.
- 로컬 기준 v10과 같은 Luna·호출 한도에서 비교한다. 새 후보 적용은 반복·허위 귀속·문장과
  계약의 불일치 및 잘못된 검토 승인을 먼저 확인하고, 실제 서비스 경계의 지연을 함께 판단한다.
  수치와 남은 검증은 [구현 기록](../implementation.md)에 남긴다.

## 영향

프롬프트 등록 시 v13 정책 구조 검증이 추가된다. 공개 API·DB 스키마와 평가 점수 산식은
기존 계약을 사용한다. 단계별 지침 바이트나 토큰 감소로 사용자 대기나 청구액을 확정하지 않는다.
