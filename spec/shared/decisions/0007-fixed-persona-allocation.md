# 0007 정상 면접의 Persona 배분을 6/2/1로 고정

- 상태: Accepted — 정책 승인, 이번 반영은 문서에 한정
- 날짜: 2026-10-06
- 결정자·검토자: 현재 사용자
- 관련 PR: [#54](https://github.com/kakaotechcampus-4/ktc4-chonnam-3/pull/54) — 기존 배분 정책 변경 이력; [#82](https://github.com/kakaotechcampus-4/ktc4-chonnam-3/pull/82) — 미병합 면접 제어 구현·후속 정합성 확인 대상
- 승인 근거: 사용자가 기술 6회·도메인 2회·HR 1회 배분의 문서 반영을 승인하고, 면접 구현 변경은 이번 범위에서 제외함.

## 맥락과 이유

[0002](0002-local-policy-baseline.md)의 고정 6/2/1 배분은
[0004](0004-flexible-persona-allocation-restoration.md)에서 기술 목표 6회·최소 5회,
도메인·HR 합산 최소 3회와 HR 재선택을 허용하는 정책으로 바뀌었다.
이번에는 정상 완료 면접의 관점별 질문 수를 명확히 고정하되, 첫 질문 이후의 순서는
답변 맥락에 따라 선택하도록 한다. 과거 결정 본문은 이력으로 보존한다.

## 결정

1. 정상 완료 면접은 첫 질문을 포함한 총 9턴이며, Persona별 질문 수는
   `tech_lead` 6회·`domain_lead` 2회·`hr_manager` 1회로 고정한다.
2. 첫 질문은 `hr_manager`이며 이 질문으로 HR 할당 1회를 사용하므로 이후 HR 질문은 허용하지 않는다.
3. 첫 질문 이후에는 Director가 Controller의 허용 후보 중 답변 맥락에 맞는 기술 또는
   도메인 관점을 선택하며, 두 관점의 순서나 교대는 고정하지 않는다.
4. Controller는 확정·제시한 질문의 Persona별 횟수와 남은 질문 수를 기준으로
   할당 초과 또는 최종 6/2/1 달성이 불가능한 후보를 제외한다.
5. Tool 호출·질문 재생성·중복 요청은 질문 횟수를 늘리지 않으며, 배분을 맞추려고
   이미 제시한 질문의 Persona를 소급 변경하지 않는다.
6. 정상 종료는 9번째 답변 처리 완료 후이며, Director의 정상 조기 종료와 10번째 질문은 허용하지 않는다.
7. 사용자 이탈·실패로 중단된 면접에는 정상 완료 배분을 강제하지 않고 기존 답변 보존·실패·재시도 정책을 유지한다.

## 영향과 검증 기준

- BE Turn 정책, AI Director와 `allowed_personas` 계약, FE 면접 명세 및 관련 task·검증 기준을 맞춘다.
- 첫 HR의 횟수 포함, 이후 HR 제외, 기술·도메인 할당 초과 거절, 서로 다른 순서의
  6/2/1 완주, 중복·재생성의 횟수 불변, 9번째 답변 후 종료와 중단 예외를 후속 구현에서 검증한다.
- 공개 API·Persona enum·DB 구조, 포트폴리오 20MB·공고 재사용 7일은 유지한다.
- 이번 변경은 문서만 반영한다. 면접 제어 코드·실행 프롬프트·FE mock fixture·설정 예시는
  수정하지 않으며, 문서 검사로 실제 배분 제어·서비스 통합 검증을 대신하지 않는다.
- 미병합 #82의 면접 제어와 FE mock 등은 후속 구현에서 이 정책에 맞춰야 한다.
  확인한 코드 기준·미반영 차이·실제 검증 결과는 [AI 구현 기록](../../ai/implementation.md)에서 관리한다.

## 대체 관계

[0004](0004-flexible-persona-allocation-restoration.md)의 유동 배분 결정을 대체한다.
[0002](0002-local-policy-baseline.md)의 6/2/1 횟수를 다시 채택하지만, 0002 자체를
현행 면접 정책으로 되돌리지는 않는다. 첫 HR·나머지 순서 자율·Controller 책임은 이 결정을 따른다.
[AI 0014](../../ai/decisions/0014-minimal-change-revision.md)의 개별 배분 비고정 부분도
현행 기준이 아니며, 면접 배분 외의 기존 결정은 유지한다.
